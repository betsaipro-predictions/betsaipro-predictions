Здесь автоматически записывается **каждая ставка нашего бота — ещё до конца матча**.
Файл `ledger.jsonl` только дополняется и никогда не переписывается: если бы мы
изменили хоть одну прошлую строку, цепочка подписей порвалась бы и это увидел бы каждый.

## Как проверить, что я не жульничаю

1. **Записано заранее.** У каждой ставки видна дата записи — она раньше конца матча.
2. **Нельзя стереть незаметно.** История хранится в GitHub; любая правка видна всем.
3. **Печать в Bitcoin.** Каждый день «отпечаток» архива штампуется в блокчейн Bitcoin
   (папка `stamps/`) — его не может переписать никто на Земле.

Ставки за каждый месяц — в папке `bets/`. Открой любой `.csv` — GitHub покажет его
таблицей.
