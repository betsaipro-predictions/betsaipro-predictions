# 🎯 Публичный архив ставок Lumex

Здесь лежит **каждая ставка нашего бота — записанная ещё ДО конца матча**. Не «удачные скриншоты», а живой поток: команда, момент игры, коэффициент, сумма и потом результат.

Файл `ledger.jsonl` **только дополняется и никогда не переписывается**. Изменили бы мы хоть одну старую строку — цепочка цифровых подписей порвалась бы, и это увидел бы любой. А раз в сутки «отпечаток» всего архива штампуется в **блокчейн Bitcoin** — переписать прошлое не сможем даже мы сами.

## 🔍 Как убедиться, что мы не жульничаем

1. **Записано заранее.** У каждой ставки видно время записи — оно раньше конца матча, подогнать под результат нельзя.
2. **Нельзя стереть незаметно.** История в GitHub; любая правка остаётся видна всем.
3. **Печать в Bitcoin.** Ежедневный отпечаток архива в блокчейне (папка `stamps/`) — его не перепишет никто на Земле.

Ставки по месяцам — в папке `bets/` (открой любой `.csv`, GitHub покажет его таблицей). Проверить цепочку самому: `python verify_ledger.py ledger.jsonl`.
